The problem

AI coding agents can report successful changes, but successful agent output alone is not independent proof that a release is safe to ship. A message saying “all tests pass” is a claim, not evidence.

ReleaseBound is an independent release verification layer. It is not an AI code generator, an AI coding assistant, or an AI code reviewer. It checks release outcomes for itself — build, tests, signing, packaging, evidence, and release readiness — instead of taking anyone’s word for it.

How it works

  1. Project Selection
  2. Release Candidate
  3. Release Verdict
  4. Required Gates
  5. Evidence
  6. Verified Baseline (Last Known Good)

You choose a project. ReleaseBound identifies the release candidate, runs the required gates, records evidence, and reports a single release verdict. Anything it cannot independently confirm is not treated as a pass.

Features

Release Candidate Verification

Verifies a specific release candidate of your project rather than a general impression of its health.

Required Gates

Checks the facts a release depends on, such as build, tests, source state, signing, and packaging.

Evidence

Records the technical results behind each gate so a verdict can be inspected, not just trusted.

Verified Baseline

Records the most recent verified release as a Last Known Good baseline. ReleaseBound keeps the latest baseline only, not a history of runs.

Local-first workflow

Designed to run on your Mac against a project folder you choose. ReleaseBound’s own code makes no network requests. See the Privacy Policy.

Platform

ReleaseBound’s initial focus is Apple platform development (macOS and iOS projects). Verification capabilities depend on the project type and the tools available on your Mac; not every verification mode applies to every language or platform.

Important limits

ReleaseBound reports what it can independently confirm. It does not guarantee that software is free of defects or vulnerabilities, does not eliminate release risk, and is not a legal, security, or compliance certification. The decision to release always remains yours. See the Disclaimer.
