Privacy Policy

Last updated: 2026-09-17

ReleaseBound is a local-first macOS application that independently verifies release-readiness facts (build, tests, source state, signing, and packaging) for a software project you choose.

What ReleaseBound accesses

ReleaseBound only reads the project folder you explicitly authorize through the macOS file picker. Access is granted under App Sandbox as read-only, and is scoped to exactly that folder using a macOS security-scoped bookmark. ReleaseBound cannot browse or read any other location on your Mac.

What ReleaseBound stores locally

  • A security-scoped bookmark for the project folder you last authorized, stored in this app's local preferences (UserDefaults) on your Mac only.
  • A Verified Release Baseline ("Last Known Good") record, written as a local file inside the authorized project folder itself, so it travels with that project rather than with ReleaseBound.
  • Verification run output and evidence produced while checking your project, kept locally on your Mac.

None of this data is transmitted anywhere by ReleaseBound.

Networking

ReleaseBound's production code makes no network requests. It does not call any server, upload any file, or communicate with any remote service. Verification runs entirely on your Mac using local tools (such as git and xcodebuild).

Analytics, tracking, and third parties

ReleaseBound contains no analytics SDK, no crash-reporting SDK, no advertising SDK, and no other third-party tracking code. It does not share data with any third party, because it does not transmit data at all.

Accounts and purchases

ReleaseBound does not require an account, sign-in, or login. It contains no purchase, subscription, or in-app payment system.

Support correspondence

If you contact support by email, any information you voluntarily include in that message (such as your email address, message content, or attachments) is received by the developer in order to respond to your request. This is separate from, and not part of, ReleaseBound's local-only project verification behavior described above.

Your control over locally stored data

You can remove ReleaseBound's local preferences and the Verified Release Baseline file it wrote into your project folder at any time, using standard macOS tools (Finder, or deleting the app's preferences). Revoking the folder authorization (for example, by choosing a different project) replaces the stored bookmark; it does not delete files inside your project.

Children's privacy

ReleaseBound is a developer tool and is not directed at children. It does not knowingly collect personal information from children, because it does not collect personal information from any user.

Security limitations

ReleaseBound is designed to fail closed: if it cannot independently verify a release fact, it reports that gate as not passed rather than guessing. No software can guarantee complete security or the absence of defects, and this Privacy Policy is not a warranty of any kind.

Changes to this policy

If ReleaseBound's data practices change (for example, if a future version adds a network-dependent feature), this Privacy Policy will be updated in the app before that feature is enabled, and the "Last updated" date above will change accordingly.
