Privacy Policy

Effective date: September 18, 2026

1. Overview

ReleaseBound is a local-first macOS application that independently verifies release outcomes for a software project you choose. This policy describes how the app and this website handle information.

2. Information processed by the macOS app

ReleaseBound may inspect local project and repository data in the folder you choose, as necessary to perform the verification you request. It stores locally on your Mac: a security-scoped bookmark for the project folder you last authorized (in the app’s local preferences), a Verified Release Baseline record written as a local file associated with your project, and verification run output and evidence.

3. Local-first processing

ReleaseBound is designed primarily for local operation on your Mac. The current version does not require an account, and its production code makes no network requests. ReleaseBound does not upload your project content to a ReleaseBound cloud service, and no such service exists.

4. Verification evidence

Verification evidence may include local file paths, hashes, and build, test, signing, and packaging results, along with related technical information. This evidence is kept locally on your Mac. You remain responsible for the repositories and information you choose to verify, and for what you do with the evidence, including whether you share it with anyone.

5. Website hosting

This website is hosted on GitHub Pages. As part of normal hosting and service delivery, GitHub may process standard web request information (such as IP address and browser details). We do not control that processing; see GitHub’s privacy statement.

6. Cookies and analytics

This website does not intentionally use analytics, advertising trackers, cookies, or behavioral tracking, and it has no cookie banner because of that. The ReleaseBound app contains no analytics, crash-reporting, or advertising SDK.

7. Data sharing

We do not sell or share your personal data. ReleaseBound does not transmit your project data anywhere. If you contact support by email or open a public GitHub issue, the information you choose to include is received by the developer (and, for public issues, is visible to others on GitHub) so that your request can be handled.

8. Security

ReleaseBound is built to fail closed: if it cannot independently confirm a release fact, it does not report a pass. No software can guarantee complete security, and this policy is not a warranty of any kind.

9. Children’s privacy

ReleaseBound is a developer tool and is not directed at children. It does not knowingly collect personal information from children.

10. Changes to this policy

If ReleaseBound’s data practices change, for example if a future version adds a network-dependent feature, this policy will be updated and the effective date will change.
